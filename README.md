# QtGalleryAppExample
a simple gallery app on qtcreator example

For practice exercices:
1. Add a 'Shuffle' button to the gallery. When clicked, it should jump to a random image. Think about what signals you'd need...
2. Try to implement drag-and-drop so you can drop new images into the gallery window and have them appear in the list. (Hint: Qt makes this surprisingly easy)
3. (Hard mode): load images in a background thread so the UI doesn't freeze when opening large files. Use queued connections to update the UI safely.
